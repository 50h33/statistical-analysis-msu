# 2023 통계적분석 중간고사 오답노트

2023년 1학기 기출을 한 소문항씩 풀며 답변, 오답, 풀이 요청, 재풀이 결과를 기록한다.

## 진행 상황

- 현재 문제: 없음.
- 현재 상태: 오답 복습 1회차 완료. 3번·8번·9번 모두 힌트 없이 정답.
- 남은 출제 순서: 없음.
- 중복 학습으로 생략: 1번 가·나·다, 2번 가·나·다, 4번 가·나, 5번, 6번. 사용자 요청에 따라 생략했으며 이번 회차 정답 판정과 구분한다.
- 정답 확인 완료: 3번·8번·9번 — 설명 후 같은 문제 재풀이 정답; 7번 — 첫 답변 정답.
- 오답 및 풀이 요청: 3번 — ddof=1일 때의 분산; 8번 — 두 정렬 코드의 차이; 9번 — df.head()의 출력 내용. 세 문항 모두 설명 후 재풀이 정답.

## 학습 및 기록 기준

- 한 소문항씩 출제하며, 말이나 일반 텍스트로 설명해도 의미가 맞으면 정답으로 인정한다.
- 2024년 또는 2025년에 공부한 동일 문제와 숫자만 바뀐 같은 풀이 유형은 생략한다. 새로운 계산 조건이나 개념이 있는 문항은 출제한다.
- 기출 원문, 관련 수업 자료, 해당 연도 풀이 파일을 대조하고 필요한 계산을 검산한다. 풀이 파일은 공식 정답지로 간주하지 않는다.
- 정답이면 다음 소문항으로 진행한다. 오답 또는 풀이 요청이면 설명 후 같은 문제를 조건과 함께 다시 제시한다. 유사 문제는 내지 않는다.
- 이미 맞힌 부분이 있으면 보완할 부분만 다시 확인한다. 계산 생략이나 진행에 관한 사용자 요청을 반영하되 실제 확인한 범위를 기록한다.
- 단순 코드 오타는 개념 이해와 구분하여 정확한 표기를 안내하고 기록한다.
- 최초 오답과 설명 후 재풀이 결과를 모두 유지한다. 답변 대기는 오답으로 분류하지 않는다.
- 원문 2번의 분산·공분산은 수업 기준 n으로 나누며, 3번은 명시된 ddof=1에 따라 n-1로 나눈다.

## 자료 확인

- 2023년 문제지 전체 1쪽을 텍스트와 렌더링 이미지로 확인했다. 1~9번 번호가 모두 있다.
- 2023년 풀이 파일의 1번 가와 출제한 3번·7번·8번·9번을 대조했다. 중복 생략 문항은 위 학습 기준 및 아래 대조 기록에 따른다.
- 4번 원문은 이산분포에 대해 ‘확률밀도함수’라고 표현한다. 해당 문항 진행 시 수업 정의에 따라 확률질량함수로 구분하여 안내한다.

### 3번 — 설명 후 재풀이 정답

- 문제: A=[1,2,3,4], B=[4,3,2,1]에 대하여 ddof=1일 때 각각의 분산을 구하시오.
- 최초 답변: “모르겠어”.
- 설명: 분산은 편차제곱합을 n-ddof로 나눈다. 두 데이터의 평균은 2.5이고 편차제곱합은 각각 2.25+0.25+0.25+2.25=5이다. n=4, ddof=1이므로 분모는 3, 두 분산은 모두 5/3이다. B는 A와 순서만 다르므로 평균과 분산이 같다.
- 대조: chap02 실습의 편차제곱합 계산과 2023년 풀이 파일 3번의 ddof=1 계산 기준 및 결과를 확인했다.
- 재답변: A 분산은 (2.25+0.25+0.25+2.25)/(4-1)=5/3, B 분산도 5/3.
- 판정: 정답. 편차제곱합과 ddof=1에 따른 분모 3을 정확히 적용했다.
- 상태: 설명 후 같은 문제 재풀이 정답. 최초 풀이 요청 기록은 유지한다.

- 판정: 정답. 10행, 5열에 해당한다.

### 8번 — 설명 후 재풀이 정답

- 문제: 같은 df에서 df.sort_values('악력', ascending=True)와 df['악력'].sort_values(ascending=True)의 출력 차이를 설명하시오.
- 출제 대조: 2023년 풀이 파일 8번의 코드와 원문 확인 기록을 대조했다.
- 최초 답변: “모르겠어”.
- 설명: 두 코드 모두 악력을 오름차순으로 정렬한다. (1)은 악력을 기준으로 행 전체를 정렬한 DataFrame을 반환하여 다섯 열이 모두 포함된다. (2)는 악력 열을 Series로 선택하여 정렬하므로 악력 값과 학생번호 인덱스만 포함된다. 두 결과 모두 학생번호와 값의 대응을 유지한다. 이 코드만 실행하면 원본 df의 순서는 바뀌지 않는다.
- 자료 대조: chap01.ipynb의 데이터 읽기 및 열 선택 예제, 2023년 풀이 파일 8번을 확인했다.
- 재답변: (1)은 악력을 기준으로 행 전체를 오름차순 정렬하며 모든 열이 나오는 DataFrame이다. (2)는 악력 열만 뽑아 오름차순 정렬하며 인덱스와 악력 값만 나오는 Series이다.
- 판정: 정답. 정렬 기준, 결과에 포함되는 열, 반환 자료형을 정확히 구분했다.
- 상태: 설명 후 같은 문제 재풀이 정답. 최초 풀이 요청 기록은 유지한다.

### 9번 — 설명 후 재풀이 정답

- 문제: 학생 10명, 다섯 열(학년·악력·윗몸일으키기·점수·순위)의 자료를 담은 df에서 df.head()가 어떤 내용을 출력하는지 설명하시오.
- 출제 대조: 2023년 풀이 파일 9번 및 chap02.ipynb의 df.head() 예제를 확인했다.
- 최초 답변: “모르겠어”.
- 설명: df.head()는 현재 행 순서에서 앞의 5개 행과 모든 열을 반환한다. df.head(5)와 같다. 이 문제에서는 5행·5열의 DataFrame이며 학생번호 인덱스도 함께 표시된다. 원본 df의 10개 행은 유지된다.
- 재답변: “현재 표의 앞 5개의 행과 열을 보여준다”.
- 판정: 앞 5행을 보여준다는 의미로 정답 인정. 정확한 표현은 ‘앞 5개 행과 모든 열’이라고 보완했다. 열 개수를 5개로 제한하는 기능은 아니다.
- 상태: 설명 후 같은 문제 재풀이 정답. 최초 풀이 요청 기록은 유지한다.
