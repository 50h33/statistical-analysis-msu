- 답변: “V(X) = {(1-3.5)^2 + (2-3.5)^2 + (3-3.5)^2 + (4-3.5)^2 + (5-3.5)^2 + (6-3.5)^2}6 = (6.25 + 2.25 + 0.25 + 2.25 + 6.25) / 6 = (17.25)/6 = 2.875”
- 판정: 계산 오류. 처음 세운 편차 제곱의 합은 정확하다. 뒤의 계산에서 `(4-3.5)^2 = 0.25`가 빠져 여섯 항이 다섯 항이 되었다. 첫 식의 `}6`은 다음 식의 `/6`을 근거로 나누기 기호 생략으로 해석했다.
- 올바른 계산: (6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25) / 6 = 17.5 / 6 = 35/12.
- 복습 사항: 눈 여섯 개에 대응하는 항도 여섯 개여야 한다. 평균 3.5를 중심으로 제곱 편차가 6.25, 2.25, 0.25, 0.25, 2.25, 6.25로 대칭인지 확인한다.
- 재풀이 답변: “V(X) = {(1-3.5)^2 + (2-3.5)^2 + (3-3.5)^2 + (4-3.5)^2 + (5-3.5)^2 + (6-3.5)^2}6 = (6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25) / 6 = (17.5)/6”
- 재풀이 판정: 정답. 여섯 항을 빠짐없이 더해 6으로 나눴다. 17.5/6은 정확한 값이며 35/12와 같다. 첫 식의 `}6`은 이어지는 `/6`에 따라 나누기 기호 생략으로 해석했다.

### 복습 1회차 2번 다

- 답변: “공분산이 0이라 상관계수도 0이야”
- 판정: 오답. 공분산은 0이지만 A의 표준편차도 0이므로 상관계수는 정의되지 않는다.
- 올바른 풀이: r_AB = S_AB / (S_A S_B). A의 분산은 0, B의 분산은 4이므로 표준편차는 각각 0과 2이다. 분모가 0 × 2 = 0이며 0/0은 정의되지 않으므로 상관계수도 정의되지 않는다.
- 복습 사항: 공분산이 0일 때도 두 표준편차가 모두 양수인지 먼저 확인한다. 한쪽 표준편차라도 0이면 상관계수는 0이 아니라 정의되지 않는다.
- 재풀이 답변: “상관계수는 정의되지 않는다. A의 표준편차가 0이기 때문에 분모가 0이 되기 때문이다”
- 재풀이 판정: 정답. 상관계수가 정의되지 않는다는 결론과 A의 표준편차가 0이라는 근거를 정확히 설명했다.

### 복습 1회차 3번 다

- 문제: 독립인 공정한 6면체 주사위의 눈 A, B에 대해 X = A + B, Y = A의 상관계수를 구하고 계산 과정을 설명하시오. Cov(X,Y) = 35/12, V(A) = V(B) = 35/12를 사용해도 된다.
- 답변: “모르겠어”
- 판정: 답하지 못함. 이번 복습에서 직접 확인한 결과이며 이전 사용자 확인에 따른 완료 기록과 구분한다.
- 재풀이 답변: “V(X) = V(A) + V(B) = 35/6 / 루트 V(X)*V(Y) = 루트 35*2/12 * 35/12 = (35*루트2)/12 / 35/12 / (35*루트2)/12 = 1/루트2”
- 재풀이 판정: 정답. 전개 맥락상 루트는 V(X)V(Y) 전체에 적용하고 최종 나눗셈의 분모는 (35√2)/12 전체로 해석했다. V(Y) = V(A) = 35/12를 대입하여 표준편차의 곱과 상관계수를 정확히 구했다.
- 상태: 해설 후 재풀이 정답 확인 완료.

상관계수는 공분산을 두 표준편차의 곱으로 나눈 값이다.

$$
\rho_{XY}=\frac{\mathrm{Cov}(X,Y)}{\sqrt{V(X)}\sqrt{V(Y)}}.
$$

A와 B가 독립이므로 Cov(A,B) = 0이고,

$$
V(X)=V(A+B)=V(A)+V(B)+2\mathrm{Cov}(A,B)
=\frac{35}{12}+\frac{35}{12}=\frac{35}{6}.
$$

Y = A이므로 V(Y) = 35/12이다. 따라서

$$
\rho_{XY}=\frac{35/12}{\sqrt{(35/6)(35/12)}}
=\frac{35/12}{\sqrt{2(35/12)^2}}
=\frac1{\sqrt2}=\frac{\sqrt2}{2}.
$$

핵심 복습 사항: 분모에는 분산의 곱이 아니라 표준편차의 곱이 들어간다. 독립인 A와 B의 분산은 더할 수 있지만 X와 Y가 독립이라는 뜻은 아니다. 여기서는 X와 Y의 분산이 모두 양수여서 상관계수가 정의된다.

수업 근거: [chap05 실습 노트북](../chap05.ipynb)의 `cov_xy / np.sqrt(var_X * var_Y)`. X의 분산 전개는 분산·공분산 정의에서 얻는 보충 설명이다.

재풀이 문제: 서로 독립인 공정한 6면체 주사위 두 개의 눈을 A, B라고 하자. X = A + B, Y = A일 때 X와 Y의 상관계수를 구하고 계산 과정을 설명하시오. Cov(X,Y) = 35/12, V(A) = V(B) = 35/12를 사용해도 된다.

### 복습 1회차 4번 나

- 문제: 성공확률 p인 독립 시행을 반복한다. 첫 성공까지의 시행 횟수 X(성공한 시행 포함, 0 < p ≤ 1)의 확률질량함수를 구하고 평균과 분산을 유도하시오.
- 답변 요약: f(x) = (1-p)^(x-1)p를 제시했다. q = 1-p로 두고 등비급수를 미분하여 평균 1/p를 구했다. 미분한 식에 q를 곱하고 다시 미분한 뒤 p를 곱하여 (2-p)/p²를 구하고 이를 분산이라고 답했다.
- 판정: 부분 정답. 확률질량함수의 식과 평균은 맞고 E(X²) 계산도 맞다. 마지막 값은 분산이 아니라 E(X²)이며 평균의 제곱을 빼야 한다.
- 올바른 마무리: V(X) = E(X²) - [E(X)]² = (2-p)/p² - 1/p² = (1-p)/p².
- 표기 보완: Σq^(x-1) = 1/(1-q)는 x = 1부터 무한대까지의 합으로 해석하면 맞다. 미분하면 Σ(x-1)q^(x-2)이고, 첨자를 옮기면 평균 계산에 필요한 Σxq^(x-1)와 같은 합이다. 확률질량함수의 범위 x = 1, 2, ...와 그 외 0도 명시한다.
- 복습 사항: E(X²)는 값의 제곱을 평균 낸 것이고, 분산은 평균에서 벗어난 정도의 제곱을 평균 낸 것이다. 두 값을 연결하는 공식 V(X) = E(X²) - [E(X)]²의 마지막 뺄셈을 빠뜨리지 않는다.
- 재풀이 답변 요약: 앞선 등비급수 미분 과정을 다시 설명하고, (2-p)/p²가 E(X²)임을 명시했다. V(X) = E(X²) - [E(X)]²에 따라 1/p²를 빼서 (1-p)/p²를 구했다.
- 재풀이 판정: 평균과 분산 유도 정답. 이전 뺄셈 누락은 수정했다. 요청한 확률질량함수의 x 범위와 그 외 확률은 답변에 없어 보완을 요청하며, 이를 새로운 계산 오답으로 분류하지 않는다.
- 범위 보완 질문에 대한 답변: “모르겠어”
- 추가 판정: 확률질량함수의 범위를 답하지 못함. 평균·분산 유도의 정답 기록은 유지한다.
- 범위 설명: X는 성공한 시행을 포함한 첫 성공까지의 시행 횟수이다. 첫 시행에서 성공하면 X = 1, 두 번째에서 처음 성공하면 X = 2이며 이후도 같다. 따라서 x = 1, 2, 3, ...에서 f(x) = (1-p)^(x-1)p이고 그 외에는 0이다. 0번 만의 성공, 음수 또는 소수 번의 시행은 이 정의에서 불가능하다. 실패 횟수를 세는 다른 기하분포 정의와 구분한다. p = 1이면 이 식에서도 x = 1만 확률 1이고 x ≥ 2는 확률 0이다.
- 범위 재답변: “x가 1 이상의 정수이면 f(x) = (1-p)^{x-1} * p이고, 그 외에는 0이다”
- 최종 판정: 정답. 평균·분산 유도에 이어 확률질량함수의 범위와 그 외 확률까지 정확히 보완했다.
- 상태: 해설 후 원문 재풀이 정답 확인 완료.

### 1번 다 공정한 주사위의 분산

- 기록일: 2026-10-19
- 문제: 공정한 주사위를 한 번 던져 나온 눈 X의 분산을 구하고 계산 과정을 설명하시오.
- 실제 답변: “모르겠어.”
- 판정: 답하지 못함. 구체적으로 어느 단계가 어려웠는지는 아직 확인하지 않았다.
- 복습 상태: 해설 후 계산 방법을 정확히 재설명함. 추후 해설 없이 계산까지 재풀이 권장.
- 재풀이 답변: “각 눈에서 평균을 빼고 그걸 제곱해서 더해 그 다음 각 확률은 다 1/6이니까 거기에 1/6을 곱하면 그게 분산이다”
- 재풀이 판정: 정답. 모든 눈의 확률이 같으므로 제곱한 편차를 더한 뒤 공통 확률 1/6을 곱하는 방법이 정확하다. 최종 수치의 독립 계산은 이번 답변에서 확인하지 않았다.

분산은 각 값이 평균에서 얼마나 떨어져 있는지를 제곱한 뒤, 확률을 곱해 더한 값이다. 평균은 7/2이고 각 눈의 확률은 1/6이다.

$$
V(X)=\sum_{i=1}^{6}(x_i-\mu_X)^2f(x_i)
=\frac{1}{6}\left[\left(1-\frac72\right)^2+\left(2-\frac72\right)^2+\left(3-\frac72\right)^2+\left(4-\frac72\right)^2+\left(5-\frac72\right)^2+\left(6-\frac72\right)^2\right]
=\frac{25+9+1+1+9+25}{24}
=\frac{35}{12}.
$$

핵심 복습 사항:

- 기댓값은 각 값에 확률을 곱해서 더한다.
- 분산은 각 값에서 평균을 빼고 제곱한 것에 확률을 곱해서 더한다.
- 평균과의 차이를 그냥 더하면 양수와 음수가 상쇄되므로, 분산에서는 차이를 제곱한다.
- 이 문제에서 6으로 나누는 것은 각 눈의 확률이 모두 1/6이기 때문이다. 확률이 서로 다르면 각각의 확률을 곱해야 한다.

재풀이 질문: 각 눈과 평균 7/2를 이용해 분산을 구하는 방법을 말로 설명하고 계산식을 다시 세워보자.

### 2번 나 데이터 A와 B의 공분산

- 기록일: 2026-10-19
- 문제: A = [1, 1, 1, 1], B = [-2, -2, 2, 2]의 공분산을 구하고 계산 과정을 설명하시오. 같은 위치의 값끼리 짝지으며 4로 나눈다.
- 실제 답변: “모르겠어”
- 판정: 답하지 못함. 구체적으로 어느 단계가 어려웠는지는 아직 확인하지 않았다.
- 복습 상태: 해설 후 공분산이 0인 이유를 정확히 재설명함. 추후 해설 없이 재풀이 권장.
- 재풀이 답변: “A의 평균과 x의 값이 같아서 A의 편차가 전부 0이어서 공분산이 0이다.”
- 재풀이 판정: 정답. ‘x의 값’은 A의 각 관측값을 뜻하는 것으로 해석했다. A의 편차가 모두 0이므로 B의 편차와의 곱도 모두 0이라는 근거가 정확하다.

공분산은 두 데이터가 각자의 평균을 기준으로 함께 변하는 방향을 나타내는 지표이다. 각 데이터에서 자기 평균을 뺀 값인 편차를 구하고, 같은 위치의 편차끼리 곱한 뒤 그 곱들의 평균을 구한다.

$$
S_{AB}=\frac{1}{n}\sum_{i=1}^{n}(a_i-\bar a)(b_i-\bar b).
$$

A의 평균은 1, B의 평균은 0이므로 A의 편차는 [0, 0, 0, 0], B의 편차는 [-2, -2, 2, 2]이다.

$$
S_{AB}=\frac{0\times(-2)+0\times(-2)+0\times2+0\times2}{4}=0.
$$

핵심 복습 사항:

- 분산은 한 데이터의 편차를 자기 자신과 곱한 값들의 평균이다.
- 공분산은 두 데이터의 편차를 같은 위치끼리 곱한 값들의 평균이다. 각각의 편차를 따로 제곱하지 않는다.
- 여기서는 A가 항상 평균 1과 같아 A의 편차가 모두 0이다. 따라서 B의 편차와 곱한 값도 모두 0이다.
- 이 수업의 데이터 공분산은 관측값 개수 n으로 나눈다.

재풀이 질문: 이 문제에서 공분산이 0이 되는 이유를 A의 편차를 이용해 말로 설명해 보자.

### 2번 다 데이터 A와 B의 상관계수

- 문제: A = [1, 1, 1, 1], B = [-2, -2, 2, 2]의 상관계수를 구하고 이유를 설명하시오.
- 실제 답변: “2번 다 번에 대해서  모르겠어”
- 판정: 답하지 못함.
- 복습 상태: 해설 후 유사 문제 정답. 최초 오답 기록은 복습을 위해 유지한다.

상관계수는 공분산을 두 표준편차의 곱으로 나눈 값이다. 표준편차는 분산의 음이 아닌 제곱근이며, 분산이 0이면 표준편차도 0이다.

$$
r_{AB}=\frac{S_{AB}}{S_A S_B},\qquad S_A=\sqrt{S_A^2},\quad S_B=\sqrt{S_B^2}.
$$

앞서 구한 공분산은 0, A의 분산은 0, B의 분산은 4이다. 따라서 A의 표준편차는 0, B의 표준편차는 2이다. 상관계수 공식에 대입하면 분모가 0 × 2 = 0이므로 상관계수는 정의되지 않는다.

핵심 복습 사항:

- 공분산을 분산의 곱이 아니라 표준편차의 곱으로 나눈다.
- 0/0은 0이 아니다. 분모가 0이면 상관계수는 정의되지 않는다.
- 한 데이터의 값이 모두 같으면 그 데이터의 표준편차가 0이어서 상관계수가 정의되지 않는다.
- 공분산이 0이더라도 두 표준편차가 모두 양수인지 확인해야 상관계수를 0이라고 할 수 있다.

유사 문제 (직접 만든 연습 문제): C = [1, 2, 3, 4], D = [5, 5, 5, 5]의 상관계수를 구하고, 그 이유를 설명하시오.

- 유사 문제 답변: “C의 평균은 2.5 D의 평균은 5 / C의 분산은 2.25 + 0.25 + 0.25 + 2.25 = 5, 5/4 / D의 분산은 0 / 상관계수는 분모가 0이므로 구할 수 없다”
- 유사 문제 판정: 정답. 두 평균과 분산 계산이 정확하며, D의 표준편차가 0이어서 상관계수가 정의되지 않는다는 근거도 정확하다. ‘구할 수 없다’는 ‘정의되지 않는다’는 뜻으로 인정했다.

수업 근거: [chap03 실습 노트북](../chap03.ipynb)의 공분산을 두 표준편차의 곱으로 나누는 상관계수 계산.

### 3번 가 두 주사위의 합과 첫 번째 눈의 결합확률분포

- 문제: 독립인 공정한 6면체 주사위의 눈을 A, B라 할 때 X = A + B, Y = A의 결합확률분포를 구하시오.
- 실제 답변: “A+B는 3인데 A가 1이라면 B는 2로 특정된다. A와 B는 특정된 한 쌍이 된다. 각각은 독립적이므로 1/6 * 1/6 = 1/36, x 는 2부터 12까지, y는 1부터 6까지의 자연수일 때 확률이 1/36이고 나머지는 0이다”
- 판정: 부분 정답. 가능한 조합의 확률 1/36과 한 쌍이 특정된다는 설명은 정확하다. 그러나 x와 y의 개별 범위만 제시하여 불가능한 조합에도 양의 확률을 부여했다.
- 복습 상태: 해설 후 사용자가 y와 x-y가 각각 1부터 6까지의 정수라는 조건을 재확인하고 이해했다고 밝힘. 사용자 요청으로 유사 문제는 생략했다.

X = x, Y = y이면 A = y, B = x - y이다. 두 주사위 모두 1부터 6까지의 눈만 나올 수 있으므로, y뿐 아니라 x - y도 1부터 6 사이의 정수여야 한다.

예를 들어 (x, y) = (2, 6)은 개별 범위에는 들어가지만 B = 2 - 6 = -4이므로 불가능하고 확률은 0이다.

정수 x, y에 대해 올바른 결합확률질량함수는 다음과 같다.

$$
f_{XY}(x,y)=\begin{cases}
1/36,&1\le y\le6,\quad1\le x-y\le6,\\
0,&\text{그 외}.
\end{cases}
$$

핵심 복습 사항:

- 각각의 값이 범위 안에 있는 것과 두 값이 동시에 가능한 것은 다르다.
- 변환된 변수 X, Y에서 원래 주사위 눈 A = Y, B = X - Y를 복원하여 조건을 확인한다.

### 3번 나 두 주사위의 합과 첫 번째 눈의 공분산

- 문제: 독립인 공정한 6면체 주사위의 눈을 A, B라 할 때 X = A + B, Y = A의 공분산을 구하고 계산 과정을 설명하시오.
- 실제 답변: “모르겠어”
- 판정: 답하지 못함.
- 복습 상태: 추가 설명 후 같은 기출 소문항 재풀이 정답.
- 재풀이 답변: “Cov(X, Y) = Cov(A+B, A) = Cov(A, A) + Cov(A, B) = V(A) + 0 = 35/12”
- 재풀이 판정: 정답. 공분산의 대칭성에 의해 Cov(A, B) = Cov(B, A)이므로 제시한 전개도 정확하다.

수업의 공분산 정의는 두 확률변수의 편차를 곱한 것의 기댓값이다. 평균은 E(A) = E(B) = 7/2, E(X) = 7, E(Y) = 7/2이다.

$$
\begin{aligned}
\mathrm{Cov}(X,Y)
&=E[(X-7)(Y-7/2)]\\
&=E[((A-7/2)+(B-7/2))(A-7/2)]\\
&=E[(A-7/2)^2]+E[(B-7/2)(A-7/2)].
\end{aligned}
$$

첫 항은 A의 분산 35/12이다. 두 번째 항은 A와 B가 독립이므로 E(B-7/2)E(A-7/2) = 0이다. 따라서 공분산은 35/12이다.

같은 계산을 공분산의 성질로 짧게 쓰면 다음과 같다.

$$
\mathrm{Cov}(A+B,A)=\mathrm{Cov}(A,A)+\mathrm{Cov}(B,A)
=V(A)+0=\frac{35}{12}.
$$

핵심 복습 사항:

- 합과의 공분산은 각 항과의 공분산을 더해 계산할 수 있다.
- 자기 자신과의 공분산은 편차의 제곱을 평균 내므로 분산과 같다.
- A와 B는 독립이므로 둘 사이의 공분산은 0이다.
- X와 Y에는 A가 공통으로 들어 있다. A와 B가 독립이라고 X와 Y도 독립인 것은 아니다.

유사 문제 (직접 만든 연습 문제): 서로 독립인 공정한 6면체 주사위의 눈을 A, B라 하자. X = A + B, Y = B일 때 X와 Y의 공분산을 구하고 이유를 설명하시오. 주사위 하나의 분산 35/12를 사용해도 된다.

- 유사 문제 답변: 없음. 사용자가 같은 기출 문제를 재풀이하는 방식으로 변경 요청함.
- 유사 문제 판정: 원문 재풀이로 대체. 유사 문제 자체는 채점하지 않음.

### 4번 나 기하분포의 확률질량함수와 평균 및 분산

- 문제: 성공확률 p인 독립적인 시행을 반복할 때 첫 성공까지의 시행 횟수 X의 확률질량함수를 구하고 평균과 분산을 유도하시오. 성공한 시행을 포함하며 0 < p ≤ 1이다.
- 실제 답변: “모르겠어”
- 판정: 답하지 못함.
- 복습 상태: 해설 후 원문 재풀이 정답. 확률질량함수와 평균 및 분산 유도 과정을 정확히 설명함.

x번째에 처음 성공하려면 앞의 x-1번은 모두 실패하고 마지막에 성공해야 한다. 따라서 x가 양의 정수일 때 f(x) = (1-p)^(x-1)p이고 그 외에는 0이다. 예를 들어 세 번째 첫 성공은 실패, 실패, 성공이므로 확률이 (1-p)^2 p이다.

수업 자료는 등비급수를 미분하여 평균과 분산을 유도한다. 아래는 같은 방법을 실패확률 q = 1-p로 치환하여 정리한 보충 설명이다. 0 < p < 1에서 유도하고 p = 1은 직접 확인한다.

등비급수와 그 미분은 다음과 같다.

$$
\sum_{x=0}^{\infty}q^x=\frac{1}{1-q},\qquad
\sum_{x=1}^{\infty}xq^{x-1}=\frac{1}{(1-q)^2}.
$$

따라서 평균은

$$
E(X)=p\sum_{x=1}^{\infty}xq^{x-1}
=\frac{p}{(1-q)^2}=\frac1p.
$$

미분한 식 양변에 q를 곱한 뒤 다시 미분하면 다음과 같다.

$$
\sum_{x=1}^{\infty}xq^x=\frac{q}{(1-q)^2},\qquad
\sum_{x=1}^{\infty}x^2q^{x-1}=\frac{1+q}{(1-q)^3}.
$$

따라서 X의 제곱의 기댓값과 분산은

$$
E(X^2)=\frac{p(1+q)}{(1-q)^3}=\frac{2-p}{p^2},
$$

$$
V(X)=E(X^2)-[E(X)]^2
=\frac{2-p}{p^2}-\frac1{p^2}
=\frac{1-p}{p^2}.
$$

p = 1이면 항상 첫 시행에서 성공하므로 X = 1, 평균 1, 분산 0이며 최종 공식과 일치한다.

핵심 복습 사항:

- X는 첫 성공 전 실패 횟수가 아니라 성공한 시행을 포함한 전체 시행 횟수이므로 1부터 시작한다.
- 확률질량함수에서 실패 횟수는 x-1, 마지막 성공 확률은 p이다.
- 평균은 1/p, 분산은 (1-p)/p^2이다.
- 평균 유도에는 등비급수의 미분을 사용한다. 분산 유도에는 E(X^2)를 구한 뒤 평균의 제곱을 뺀다.

자료 정정: [chap06 평균·분산 보충자료](../chap06_이산형_확률변수_평균분산.pdf) 20쪽의 E(X^2) 유도 중 미분 결과 앞 계수가 p로 적힌 곳은 -p이어야 한다. 최종 결과 (2-p)/p^2 및 분산 공식은 맞다. 19쪽의 1/(1-p)를 사용하는 중간 전개는 p = 1에서 나눗셈이 불가능하므로 해당 끝점은 위처럼 별도로 확인한다.

재풀이 질문: 성공확률 p인 독립 시행에서 첫 성공까지의 시행 횟수 X의 확률질량함수, 평균, 분산과 유도 과정을 다시 설명해 보자. 위 등비급수 식을 참고해도 된다.

- 재풀이 답변 요약: f(x) = (1-p)^(x-1)p를 제시하고 q = 1-p로 치환했다. 등비급수를 미분한 합에 p를 곱해 평균 1/p를 유도했다. 미분한 합에 q를 곱하고 다시 미분한 뒤 p를 곱해 E(X^2) = (2-p)/p^2를 얻었으며, 평균의 제곱을 빼서 분산 (1-p)/p^2를 유도했다.
- 재풀이 판정: 정답. 일반 텍스트의 `1+q / (1-q)^3`, `2-p / p^2`, `1-p / p^2`는 전개 맥락상 분자 전체를 묶은 (1+q)/(1-q)^3, (2-p)/p^2, (1-p)/p^2로 해석했다.
- 표기 보완: 등비급수 Σq^x는 x = 0부터 무한대까지이며, 평균과 E(X^2)의 합은 x = 1부터 무한대까지이다. 확률질량함수는 x = 1, 2, ...에서 해당 식이고 그 외에는 0이라는 범위를 함께 적으면 완전하다. 유도 원리는 정확하므로 표기 생략을 별도 오답으로 분류하지 않았다.

### 5번 이항분포의 평균과 분산

- 문제: 성공확률 p = 0.3인 베르누이 시행을 서로 독립적으로 10번 반복한다. 성공 횟수 X의 평균과 분산을 구하고 공식이나 계산 과정을 설명하시오.
- 실제 답변: “모르겠어”
- 판정: 답하지 못함.
- 복습 상태: 해설 후 원문 재풀이 정답. 평균과 분산 공식 적용 및 계산이 정확함.

각 시행에서 성공하면 1, 실패하면 0인 확률변수를 X_i라 하면, 전체 성공 횟수는 X = X_1 + ... + X_10이다. 각 X_i는 베르누이분포를 따르므로 평균은 p = 0.3이고 분산은 p(1-p) = 0.21이다.

합의 평균은 각 평균의 합이다.

$$
E(X)=\sum_{i=1}^{10}E(X_i)=10\times0.3=3.
$$

각 시행이 서로 독립이므로 공분산 항은 0이며, 합의 분산도 각 분산의 합이다.

$$
V(X)=\sum_{i=1}^{10}V(X_i)=10\times0.3\times0.7=2.1.
$$

일반적으로 X가 n번의 독립적인 베르누이 시행에서 성공 횟수인 이항분포를 따르면 E(X) = np, V(X) = np(1-p)이다.

핵심 복습 사항:

- 베르누이분포는 한 번의 성공 여부, 이항분포는 n번의 독립 시행에서 성공한 횟수이다.
- 한 번의 평균 p와 분산 p(1-p)를 각각 n번 더하면 이항분포의 공식이 된다.
- 서로 독립인 확률변수 n개의 합의 분산은 각 분산의 합이다. 같은 확률변수 하나를 n배 한 경우의 분산 n^2 V(X)와 구분한다.

수업 근거: [chap06 실습 노트북](../chap06.ipynb)의 이항분포 및 n = 10, p = 0.3 설정과 [평균·분산 보충자료](../chap06_이산형_확률변수_평균분산.pdf)의 이항분포 평균·분산. 위 설명은 같은 결과를 독립인 베르누이 확률변수들의 합으로 유도한 보충 설명이다.

재풀이 문제: 성공확률이 p = 0.3인 베르누이 시행을 서로 독립적으로 10번 반복한다. 성공한 횟수를 X라고 할 때 X의 평균과 분산을 구하고, 사용한 공식이나 계산 과정도 설명하시오.

### 6번 NumPy 공분산 행렬

- 문제: 영어 점수 배열 en_scores와 수학 점수 배열 ma_scores의 공분산 행렬을 NumPy로 구하고, 결과에서 각 과목의 분산과 두 과목의 공분산의 위치를 설명하시오. 수업 기준에 따라 데이터 개수 n으로 나눈다.
- 실제 답변: “알려줘”
- 판정: 답안을 제출하지 않고 풀이를 요청함. 복습 대상으로 기록한다.
- 복습 상태: 해설 후 개념 정답. 함수 선택, ddof 설정, 행렬 인덱스가 정확하며 변수명 오타를 보완 안내함.

수업 노트북과 같이 `np.cov()`를 사용하고 `ddof=0`을 지정한다.

```python
import numpy as np

cov_mat = np.cov(en_scores, ma_scores, ddof=0)
```

배열 인덱스는 0부터 시작하며, 입력한 순서대로 0은 영어, 1은 수학을 뜻한다.

| 위치 | 의미 |
| --- | --- |
| cov_mat[0, 0] | 영어 점수의 분산 |
| cov_mat[1, 1] | 수학 점수의 분산 |
| cov_mat[0, 1] | 영어와 수학 점수의 공분산 |
| cov_mat[1, 0] | 같은 공분산 |

대각 원소는 각 과목과 자기 자신의 공분산이므로 분산이고, 비대각 원소는 서로 다른 두 과목의 공분산이다. 공분산은 순서를 바꾸어도 같으므로 두 비대각 원소도 같다.

핵심 복습 사항:

- `np.cov()`의 반환값은 공분산 하나가 아니라 분산과 공분산이 들어 있는 행렬이다.
- 이 문제처럼 가중치를 지정하지 않은 경우 분모는 n-ddof이다. `ddof=0`은 n으로 나눈다.
- `np.cov(en_scores, ma_scores)`처럼 다른 옵션 없이 ddof를 생략하면 기본적으로 n-1로 나눈다.
- 대각선은 분산, 나머지 두 칸은 공분산이다.

수업 근거: [chap03 실습 노트북](../chap03.ipynb)의 `cov_mat` 생성 및 원소 접근 코드. 계산 기준은 설치된 NumPy 문서와 간단한 배열 실행 결과로도 확인했다.

재풀이 문제: en_scores와 ma_scores는 각각 영어와 수학 점수 배열이다. 두 배열의 공분산 행렬을 구하는 NumPy 코드를 적고, 반환된 행렬에서 영어 분산, 수학 분산, 두 과목의 공분산이 어느 위치에 있는지 설명하시오. 데이터 개수 n으로 나누도록 작성하시오.

- 재풀이 답변:

```python
import numpy as np

cov_mat = np.cov(en_scores, ma_scroes, ddof=0)
en_v = cov_mat[0, 0]
ma_v = cov_mat[1, 1]
en_ma_cov = cov_mat[0, 1]
```

- 재풀이 판정: 개념 정답. `ma_scroes`는 문제에 주어진 `ma_scores`의 오타이므로 고쳐야 실행된다. 함수, n으로 나누는 설정, 두 분산과 공분산의 위치는 모두 정확하다. 단순 변수명 오타를 새 개념 오답으로 분류하지 않았다.

### 9번 포아송분포 생성과 평균 및 분산 계산

- 문제: 포아송분포의 모수 λ 값이 변수 lam에 저장되어 있다. scipy.stats로 포아송분포 객체를 생성하고 그 분포의 평균과 분산을 구하는 코드를 작성하시오.
- 실제 답변: “알려줘”
- 판정: 답안을 제출하지 않고 풀이를 요청함. 복습 대상으로 기록한다.
- 복습 상태: 해설 후 원문 재풀이 정답. 포아송분포 생성과 평균·분산 메서드 호출이 모두 정확함.

추가 개념 설명 요청: “포아송 분포가 뭔지부터 설명해줘”. 이 요청은 새 오답으로 분류하지 않는다.

포아송분포는 정해진 시간 동안 사건이 몇 번 발생하는지 나타내는 확률분포이다. 수업 자료에서는 단위 시간당 발생 건수의 분포로 정의한다. X는 실제 발생 횟수로 0, 1, 2, ...를 취하고, λ는 같은 시간 구간에서의 평균 발생 횟수이다. 평균이 λ라고 매번 정확히 λ번 발생하는 것은 아니다.

수업 예시: 하루 평균 교통사고가 2건인 지역의 하루 사고 건수를 X라 하고 포아송분포로 모델링하면 X는 Poi(2)를 따른다. 이 모델에서 하루 사고가 0건일 확률은 다음과 같다.

$$
P(X=0)=\frac{e^{-2}2^0}{0!}=e^{-2}\approx0.135.
$$

일반적으로 λ > 0에서 확률질량함수는 P(X=x) = e^(-λ)λ^x/x! (x = 0, 1, 2, ...)이고, 평균과 분산은 모두 λ이다. 따라서 λ = 2이면 평균 2, 분산 2이다. SciPy에서는 이 λ 값을 `mu` 인수에 넣으므로 `stats.poisson(mu=2)`로 표현한다.

모델링에 관한 보충 설명: 평균 횟수만 안다고 자동으로 포아송분포가 되는 것은 아니다. 일정한 발생률로 사건이 독립적으로 발생하는 상황을 나타내는 데 흔히 사용한다. 여기서 λ는 선택한 시간 구간에 맞춰 정한다.

개념 근거: [chap06 대표적인 이산형 확률변수](../chap06_대표적인_이산형_확률변수.pdf) 24–26쪽의 정의, 사고 건수 예시, 평균·분산 공식.

```python
from scipy import stats

rv = stats.poisson(mu=lam)
mean = rv.mean()
variance = rv.var()
```

핵심 복습 사항:

- `stats.poisson()`으로 포아송분포 객체를 생성한다.
- 수학에서 λ로 쓰는 모수는 이 함수에서 `mu`라는 인수에 전달한다. `lam`은 그 값을 담아 둔 변수 이름이다.
- `rv.mean()`은 평균, `rv.var()`는 분산을 계산한다. 함수를 호출하는 괄호 `()`를 붙인다.
- `stats.poisson(lam)`처럼 위치 인수로 전달해도 같다.
- 기본 위치 설정의 포아송분포는 평균과 분산이 모두 λ이므로, 위 두 계산 결과는 모두 lam과 같다.
- 실제 난수 하나를 뽑는 것은 추가로 `x = rv.rvs()`를 호출하는 별도 작업이다.

수업 근거: [chap06 실습 노트북](../chap06.ipynb)의 `stats.poisson(lam)` 및 `rv.mean(), rv.var()`. 함수의 인수 이름과 메서드는 [SciPy 공식 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.poisson.html)로 확인했다. 현재 Python 환경에는 SciPy가 설치되어 있지 않아 실행 검증은 하지 못했다.

재풀이 문제: 포아송분포의 모수 λ 값이 변수 lam에 저장되어 있다고 하자. scipy.stats를 이용해 포아송분포 객체를 생성하고, 그 분포의 평균과 분산을 구하는 코드를 작성하시오.

- 재풀이 답변:

```python

rv = stats.poisson(mu=lam)
mean = rv.mean()
variance = rv.var()
```

- 재풀이 판정: 정답. 모수 lam인 포아송분포 객체를 생성하고 mean()과 var()를 호출하여 평균과 분산을 구했다. 실제 실행 검증이 아닌 수업 자료 및 공식 문서에 근거한 코드 채점이다.
